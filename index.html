Memory That Learns What Matters

T²Mem stores experience in fast weights that update as the robot observes. Action supervision teaches the policy what to remember and how to use it.

Read the abstract

Memory-dependent robotic manipulation requires policies to use information that is no longer available in the current observation. Retaining history alone is insufficient: memory must preserve information that supports future actions. T²Mem develops this capability within a pretrained vision-language-action policy, without external reasoning models or memory-specific annotations. An observation-grounded interface extracts vision-language information, while online self-supervised updates encode history in compact fast weights. Action supervision shapes what the memory learns to retain and use. Alternating memory–policy learning gives each component a fixed counterpart during optimization. Across 16 RoboMME tasks, T²Mem improves average success from 17.93% to 56.83% over the memory-free base policy. Memory interventions test how stored history guides decisions, and controlled profiling measures the computational cost of inference.
